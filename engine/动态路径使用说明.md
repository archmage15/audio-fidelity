# 动态音频路径与批量缓存

保留先缓存范本、再评测跟读的流程。音频无需复制到 audio，也无需改成固定文件名。

## 双击使用

1. 双击 `批量缓存原音频.bat`，输入原音频文件夹完整路径。文件夹中的每段音频分别建立缓存。
2. 双击 `指定音频路径评测.bat`，分别输入原音频文件路径和模仿音频文件路径。
3. 控制台最后显示本次报告路径；默认每次写入 output/runs 下的新目录。

批量缓存默认只处理该文件夹直接包含的 wav/mp3/flac/ogg；已有有效缓存会跳过。
音频扩展名大小写均可。m4a/aac 仍需先转换。缓存时调用讯飞转写，会使用配置中的服务额度。
默认自动采用转写结果；需要逐个核对时，命令行增加 --confirm-text。
缓存失败会记录原因并继续其他文件，最后输出缓存清单。
原有两个一键评测入口不带参数时仍沿用原来的 audio 文件夹流程。

## PowerShell 命令行

先进入本项目根目录，再执行：

```powershell
.\.venv\Scripts\python.exe .\cache_audio.py "E:\英语素材\范本"
# 包含子目录：
.\.venv\Scripts\python.exe .\cache_audio.py "E:\英语素材\范本" --recursive
# 也可以单独缓存一个音频：
.\.venv\Scripts\python.exe .\cache_audio.py "E:\英语素材\范本\lesson 01.wav"

.\.venv\Scripts\python.exe .\evaluate.py --reference "E:\英语素材\范本\lesson 01.wav" --imitation "E:\我的录音\练习 01.wav"
# 或使用两个位置参数；输出目录必须是空目录：
.\.venv\Scripts\python.exe .\evaluate.py "E:\范本.wav" "E:\跟读.wav" --output "E:\测评结果\本次"
```

原来的单句/长文本 bat 也支持转发上述 evaluate.py 参数。

## Python 调用

在项目可导入路径中：

```python
from evaluate import evaluate
result = evaluate(reference=r"E:\范本.wav", imitation=r"E:\跟读.wav")
print(result["score"], result["report"])
```

## 缓存与结果

- 缓存库：tmp/reference_cache，以原音频内容的 SHA256 区分。
- 相同内容改名后仍可复用；同名但内容不同的文件会建立不同缓存。
- 默认运行结果：output/runs/日期时间_随机编号，每次独立保存报告、JSON、图表和日志。
- 每个结果目录的 run.json 记录实际输入路径、内容哈希、缓存位置和执行状态。
- 批量缓存清单：output/cache_batches/日期时间_随机编号/缓存清单.json。
- 现有已确认的原音频缓存会在内容一致时复用，不需要重新转写。
- 直接评测未缓存的范本会明确提示先缓存，不会偷偷套用其他范本。
- 自定义缓存库可对缓存和评测命令都传入同一个 --cache-dir。

模型仍共用现有 models 目录。原音频和模仿音频都只读，转写文本由本次范本得到，不使用内置示例台词。

## CPU 使用限制

Windows 和 Linux 的缓存、评测入口会自动设置 CPU 亲和性。
最多使用 3 个逻辑核心；首次启动按当前可用逻辑核心数减 1 计算，最少使用 1 个：

| 当前可用逻辑核心 | 本程序最多使用 |
| --- | --- |
| 4 个及以上 | 3 个 |
| 3 个 | 2 个 |
| 2 个 | 1 个 |
| 1 个 | 1 个，无法留出空闲核心 |

同一流水线的子进程继承同一组核心，避免每个阶段各占一组核心。
同时限制 PyTorch、OpenMP、BLAS 等计算库的工作线程，启动日志会显示核心编号。
这里限制的是可执行计算的逻辑核心数，任务管理器中的进程总线程数仍可能大于 3。
留出的核心不供本程序计算，但其他程序和系统仍可使用；不保证其始终处于空闲状态。
例如共 4 个逻辑核心时，本程序满载占整机 CPU 的理论上限约为 75%。

可将计算线程进一步降低，但不能通过该变量突破核心上限：

```bash
AUDIO_TEST_CPU_THREADS=1 bash linux.sh evaluate /data/ref.wav /data/mine.wav
```

Windows PowerShell 示例：`$env:AUDIO_TEST_CPU_THREADS='1'`，再启动评测。
限制从下次启动生效。若手动同时开启多条独立流水线，各自受限，不构成整机的统一资源配额。
